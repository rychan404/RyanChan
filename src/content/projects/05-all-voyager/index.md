# Overview

All Voyager helps first-time and experienced travelers find their next destination. You pick your budget and whether you want a rural or urban trip, then explore detailed cards for each recommended location to plan with confidence.

# What I made
- **Recommendation module**: Built the backend that matches destinations to your budget and preferences, with FastAPI and Python.
- **Frontend Design**: Built the location cards and the rest of the interface with React, TypeScript and Tailwind CSS.

# Challenges
- **Paid data**: Most travel data services cost money we were not willing to spend, so we had to work around them.
- **Too many ideas**: We struggled to narrow our ideas and features down to something we could finish.
- **Uneven experience**: Some teammates hadn't worked with APIs before, so connecting the pieces took extra time.

# Takeaways
I learned how to build a web application from start to finish with technologies such as React/TypeScript and FastAPI/Python, and what a typical software sprint looks like.
